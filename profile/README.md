## How we engineer

- **WordPress Coding Standards:** PHPCS and PHP compatibility checks on every change, for PHP 7.4 to 8.4.
- **Automated tests:** PHPUnit against the oldest supported and the latest WordPress.
- **Secure by default:** capability and nonce checks on every write, escaped output, prepared queries and Plugin Check.
- **Guarded releases:** code review, CI and protected release tags. Nothing reaches WordPress.org untested.
